# Appendix: Quick Reference Commands

## ⚡ Quick Reference

Use the following commands and utilities as a quick reference while completing the labs.

| **Command / Tool**  | **Purpose**                                     |
| ------------------- | ----------------------------------------------- |
| `ipconfig /all`     | Display all network adapter configurations      |
| `ping <host>`       | Test connectivity and latency                   |
| `nslookup <domain>` | Query DNS resolution                            |
| `tracert <host>`    | Trace network route to destination              |
| `netstat -an`       | Show all active connections and listening ports |
| `Services.msc`      | Manage Windows services                         |
| `gpedit.msc`        | Edit local Group Policy                         |
| `dsa.msc`           | Open Active Directory Users and Computers       |
| `gpupdate /force`   | Refresh Group Policy immediately                |

---

## 📋 Recommended Prerequisites

Before beginning the labs, ensure the following prerequisites are available:

* 🪟 **Windows 10/11 or Windows Server 2019/2022 environment**
* 🏢 **Access to a domain controller or domain-joined machines** (for AD labs)
* 🔑 **Administrative/elevated privileges** on test systems
* 🌐 **Basic understanding of networking** (TCP/IP, DNS, DHCP)
* 💻 **Familiarity with command-line interfaces** (CMD, PowerShell)

---

## 🧭 Lab Progression

These **8 labs** progress from foundational networking concepts to advanced Active Directory management.

> **Recommended learning path:** Complete the labs **in order for maximum learning benefit**.

Each lab builds on concepts from previous labs, allowing learners to progressively develop their networking, Windows administration, Group Policy, and Active Directory skills.
